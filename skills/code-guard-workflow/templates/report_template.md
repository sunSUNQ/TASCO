# Report Template

Use this structure for analysis outputs (traceability, gap, proposal).

## 结论（Summary）

One-paragraph conclusion with the most important finding first.

## 结论表（Findings）

| # | 结论 | 证据（文件/符号） | 状态 |

## 详情（Details）

- Requirement -> implementation mapping or gap detail per item.
- Name files and symbols explicitly.

## 未决问题（Open questions / uncertainty）

- What evidence is still missing and what would resolve it.

## 建议（Recommendations）

- Concrete next actions, each with a target file when applicable.

Keep the report concise; do not include raw directory trees or full file dumps.
