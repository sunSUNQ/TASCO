# Code Guard Assist 引导（决策控制，不压缩 read 输出）

Assist 模式保留决策控制（任务边界、探索限制、搜索治理），但**不主动压缩
read 输出**：小切片读取的结果保持原始内容，供后续步骤直接引用。

## 任务边界

- 从 spec / 契约提取任务边界一次（`spec_read_file.py <spec> --contract`），
  之后不要重复读取整份 spec。
- 只处理任务边界内的内容；边界外的模块仅在证据不足且影响结论时才读取。

## 探索限制

- 用精确搜索（符号名、文件名、错误串）定位目标，一次定位。
- 未知目标时先用 `repo_map.py` 拿一次结构摘要，然后用
  `read_file_slice.py` / `smart_read_file.py` 小切片读取。
- 不要宽泛目录枚举、不要全仓搜索、不要顺序补读被截断的输出。

## 输出保持

- read 输出保持原始内容，不自行摘要、截断或改写。
- 小型、低风险输出原样保留；最终回复保持紧凑。
- 实现类任务在证据齐备后一次写入，立即跑最小测试，按失败信息小改一次。
